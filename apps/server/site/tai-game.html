❓ Hướng dẫn cài

  1. 1
    Tải bộ cài exe ở trên, mở file vừa tải rồi chọn thư mục cài.
  2. 2
    Windows hiện "Windows protected your PC": bấm More info → Run anyway. Game chưa mua chứng chỉ ký số nên Windows cảnh báo — file vẫn an toàn.
  3. 3
    Bị chặn hẳn (máy công ty, phần mềm diệt virus)? Tải gói zip, giải nén, chạy Aether.exe.
  4. 4
    Mở game → Tạo tài khoản (hoặc dùng tài khoản đã tạo trên web) → tạo nhân vật.
  1. 1
    Tải file APK ở trên (khoảng 180 MB — nên dùng wifi).
  2. 2
    Mở file vừa tải (thanh thông báo hoặc ứng dụng Tệp / Files → Tải xuống).
  3. 3
    Máy hỏi thì bật Cho phép cài ứng dụng từ nguồn này, quay lại rồi bấm Cài đặt.
  4. 4
    Play Protect cảnh báo "ứng dụng không rõ"? Bấm Chi tiết → Vẫn cài đặt.

💡 Câu hỏi thường gặp

Có phải tải lại mỗi khi có bản mới?
Không. Mở game là game tự kiểm tra và cập nhật lên bản mới nhất. Chỉ tải lại khi cài máy mới.
Đổi máy / cài lại có mất nhân vật không?
Không. Tài khoản và nhân vật lưu trên máy chủ — đăng nhập ở máy nào cũng chơi tiếp được, PC lẫn điện thoại.
Vì sao Windows / Android cảnh báo khi cài?
Game đang beta, chưa phát hành qua cửa hàng và chưa ký số nên hệ điều hành cảnh báo với mọi ứng dụng như vậy. So mã SHA-256 bên dưới nếu muốn chắc file tải về đúng.
Gặp lỗi khi cài hoặc khi chơi?
Gửi ở trang Góp ý (chọn "Báo lỗi") — đội làm game trả lời ngay ở đó.
